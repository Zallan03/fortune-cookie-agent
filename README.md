One funny fortune-cookie line for an AI agent, written by a program.

Entry for the [Fortune Cookie for an AI Agent](https://make.fun/c/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on [make.fun](https://make.fun/r/tmbrnhrj).

## The fortune

> You will soon meet a human who pastes a 40-page PDF, asks for a quick summary, and never reads it.

## How it works

`main.ts` writes the fortune to `/output/entry.txt` — a single line, 98 characters, no trailing newline.

```sh
node main.ts
```
